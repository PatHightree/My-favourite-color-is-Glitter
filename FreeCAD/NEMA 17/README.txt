NEMA 17 stepper motor FreeCAD model (17HS4401S) by BenjaminW on Thingiverse: https://www.thingiverse.com/thing:6761583

Summary:
I was fed up because I couldn't find a decent 3D model of a bog-standard NEMA 17 stepper motor like they're used in 3D printers, so I designed my own. This is an accurate and detailed model of the 17HS4401S, which I think is a fairly common stepper nowadays.You can change the length in FreeCAD by simply changing the linear pattern named "stack" in the "stator" body to a higher number of occurences and total length, then moving the front endcap and bearing up in Z a bit. That shouldn't break any dependencies (I think...)I really should've made it parametric, but that's a project for another day.There is a slight bug that crept in after I added screws in the Fasteners workbench; it keeps randomly displaying obscure error messages whenever you open or save the file, but those don't seem to affect anything, so I just ignored them. You can just delete the screws if it bothers you.Anyway, enjoy!
